Sorbo — Mockups

Diseño de pantallas y estados para la preentrega. Material Design 3 (Jetpack Compose material3), base de 360dp de ancho, adaptable de 320 a 412dp. Son 50 frames: cada teléfono es un frame independiente para importar a Figma con el plugin html.to.design. Las miniaturas de colores representan las fotos de las etiquetas.

0 · Sistema de diseño

Tokens de color de Material 3 generados a partir del bordó de la marca. En Compose se definen en ColorScheme y Typography del tema, así cada componente los toma automáticamente y el modo oscuro sale de los mismos tokens.
